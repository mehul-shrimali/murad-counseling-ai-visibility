# Murad Counseling AI Visibility Report

A measured report on how ChatGPT and Gemini answer OCD care questions across Texas, Washington, New Hampshire, and Florida, prepared by [Glace](https://glace.sh) on November 26, 2026.

- **Report:** https://mehul-shrimali.github.io/murad-counseling-ai-visibility/
- **Method:** 15 questions built from documented patient language (Google Autocomplete, IOCDF guidance, community patterns), asked to ChatGPT (GPT-5.6 with live web search) and Gemini (Gemini 3.6 Flash with Google Search grounding), two runs each. 60 answers total.
- **Raw transcripts:** [`data/answers/`](data/answers/) — every answer as collected, unedited.
- **Question manifest:** [`data/manifest.json`](data/manifest.json) — each question with its market and intent.

All observations are dated. Items read from search engine indexes (where live pages refuse automated readers) are marked as such in the report.
